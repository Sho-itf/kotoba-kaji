# 見た目の見本

ことば鍛冶の新しい見た目(墨の地・朱・筆の跡)を確かめるための見本です。3 つの画面(待機・稽古中・結果)を、決め打ちの例で並べています。キーを打っても動きません。

公開するサイトには入りません。本番の画面には、型と称号を作ったあとで移す予定です。

## 開き方

```bash
npm run dev
```

表示された URL の後ろに `/design/mihon/` を付けて開きます(例:`http://localhost:5173/design/mihon/`)。上の細い帯で、画面や状態(ミス・一本・段と級・知らせ・筆の跡の濃さ)を切り替えられます。

- `mihon.css` の先頭に、色・線の太さ・字の間隔・筆の跡の濃さの変数をまとめています
- `brush.svg` は背景の筆の跡です(外部の画像は使っていません)
