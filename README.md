# ことば鍛冶

語彙アプリ [Vorge](https://github.com/Sho-itf/Vorge) の兄弟アプリで、ローマ字のタイピングの稽古です。
Vorge の語彙の例文を漢字のまま出し、その読みをローマ字で打ちます。打ち終えたら、語の意味を見せます。

公開先:<https://sho-itf.github.io/kotoba-kaji/>

ブラウザだけで動きます。パソコン(物理のキーボード)向けで、スマホでの利用は想定していません。

## 遊び方

- Enter か Space で稽古を始めます。Esc で中断できます(中断した回は記録しません)。
- 稽古は 60 秒から始まります。お題の例文が出るので、その読み(ひらがな)をローマ字で打ちます。打ち終えたら、すぐ次の文に進みます。
- 「、」「。」「「」」などの記号は、打たずに自動で飛ばします。
- ローマ字の打ち方は、1 通りに決まっていなくてもかまいません(shi と si、chi と ti など)。
- ミスなしで打ち終えた文は「一本」と数えます。一本を続けて取ると残り時間が延びます(1 本目は 0.5 秒、2 本目からは 1 秒ずつ)。ミスのある文で終えると、連続は 0 に戻ります。
- 結果は、打鍵数・正確さ・打てた文の数・一本の数・スコアで出ます。スコアは「正しく打ったキーの数 × 正確さ」(小数点以下は切り捨て)です。
- 位(級・段)は、1 回の稽古ごとに決まります。名乗る位は、これまでの稽古で取れた、いちばん高い位で、下がりません。表の数字を変えたときも、記録を読むときに今の表で計算し直し、上がることはあっても下がりません。
  - 級(十級〜一級)は、スコアだけで決まります。
  - 段(初段〜十段)は、1 回の稽古で、スコアと正確さの両方が下の線を超えたときに、その段になります。正確さは、画面に出る値(小数第 1 位まで、それ以下は切り捨て)で比べます。

| 位 | スコア | 正確さ | 位 | スコア | 正確さ |
|---|---|---|---|---|---|
| 十級 | 0 | | 初段 | 230 | 80% |
| 九級 | 40 | | 二段 | 260 | 85% |
| 八級 | 60 | | 三段 | 300 | 87.5% |
| 七級 | 80 | | 四段 | 350 | 90% |
| 六級 | 100 | | 五段 | 400 | 91% |
| 五級 | 120 | | 六段 | 440 | 92% |
| 四級 | 140 | | 七段 | 480 | 93% |
| 三級 | 160 | | 八段 | 520 | 94% |
| 二級 | 180 | | 九段 | 560 | 95% |
| 一級 | 200 | | 十段 | 600 | 96% |

例:スコア 320・正確さ 86% なら、二段です(三段には 87.5% が要ります)。

- 記録(ベスト、名乗る位、直近 100 回の稽古、ミスしたキーの合計)は、ブラウザの中(localStorage)に保存します。サーバーには送りません。
- 待機の画面の下から、記録を JSON のファイルに書き出したり、取り込んだりできます。ブラウザを変えるときなどに使えます。

## 開発の仕方

Node.js(24 を想定)が要ります。画面は素の TypeScript で、作りには Vite、テストには vitest を使います。

```bash
npm install      # ライブラリを入れる
npm run dev      # 開発用のサーバーを起動する(ブラウザで確かめる)
npm test         # テスト(vitest)を流す
npm run build    # 型の確認と、公開用の dist の作成
```

main に push されると、GitHub Actions(`.github/workflows/pages.yml`)がテストとビルドを行い、GitHub Pages に公開します。

### フォルダ

- `src/romaji/` ローマ字の判定(1 キーずつ、正解の候補を絞り込む仕組み)
- `src/game/` 稽古の進行、スコア、位の表、お題の選び方
- `src/storage/` 記録の保存・書き出し・取り込み
- `src/ui/` 画面
- `public/sentences.json` アプリが読む例文と読み
- `data/` 読みの手直しの表
- `tools/` 読みのデータを作る Python のスクリプト
- `tests/` テスト

## 例文の読みのデータの作り直し

`public/sentences.json` は Git に入っているので、遊ぶだけなら作り直しは要りません。
Vorge に語彙が増えたときなどに、スクリプトで作り直します。読みは、形態素解析(文を語に分けて読みを付ける道具)の
[sudachipy](https://github.com/WorksApplications/SudachiPy) で作ります。

```bash
python -m venv .venv                                  # 仮想環境(このフォルダの中だけの Python 置き場)を作る
.venv\Scripts\pip install -r tools\requirements.txt   # Windows の場合。Mac・Linux は .venv/bin/pip
.venv\Scripts\python tools\make_readings.py [Vorge の csv フォルダ]
```

- Vorge の CSV(`csv/*.csv`)の場所は、引数で渡します。省略すると、このフォルダの隣の `Vorge/csv` を使います。Vorge のファイルは読むだけで、変更しません。
- `data/readings-fix.csv`:文ごとの読みの手直し(数字や記号を含む文など)。作り直しても、これを当て直します。
- `data/word-reading-fix.csv`:お題の語の読みの上書き。`wordReading` と、文の中のお題の語の読みの両方に使います。
- 読みがおかしいときは、止まって、理由を出します(手直しの元の文が変わった、ひらがな以外が残った、など)。
- 参考の知らせ(読みが文脈で変わりやすい字など)は、`private/check.tsv` に出ます。このファイルは公開しません。

## 例文と意味について

例文と語の意味は、Vorge のために自作したものを取り込んでいます。辞書の文は写していません。
